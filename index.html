Configuração inicial (fazer uma vez por repositório)
  1. Cria um repositório novo (pode ser privado) no GitHub, só para os builds.
  2. Copia o ficheiro build-apk.yml (fornecido junto com este index) para .github/workflows/build-apk.yml nesse repositório.
  3. Faz commit e push desse ficheiro — sem isto o GitHub não sabe como compilar.
  4. Gera um token em github.com/settings/tokens com scopes repo + workflow.
  5. Preenche os campos acima e clica "Iniciar build".

Nota sobre assinatura: o workflow gera uma keystore nova a cada build. Isso é suficiente para testar/instalar, mas se quiseres publicar actualizações da mesma app mais tarde (sem forçar desinstalação), vais precisar de fixar uma keystore fixa como secret do repositório — posso ajudar-te com isso depois.
