Configuração inicial (fazer uma vez por repositório)
  1. Cria um repositório novo (pode ser privado) no GitHub, só para os builds.
  2. Garante que .github/workflows/build-apk.yml existe nesse repositório e faz npx cap sync android a partir da pasta www/.
  3. Gera um token em github.com/settings/tokens com scopes repo + workflow.
  4. No teu backend Express (Render), monta a rota: app.use('/api/apk-build', require('./apk-build-routes')) — ficheiro fornecido separadamente.
  5. Preenche os campos acima, incluindo o URL do backend (ex: https://o-teu-backend.onrender.com/api/apk-build), e clica "Iniciar build".

Porque é que isto corrige as falhas de "Failed to fetch": antes, o telemóvel fazia dezenas de pedidos seguidos diretamente à API do GitHub — sobre uma ligação móvel fraca isso falha facilmente a meio. Agora o telemóvel faz só 1 pedido a enviar tudo para o teu servidor, e o servidor (com ligação estável) é que fala com o GitHub. O telemóvel só faz pedidos leves de status a cada 3s.

Nota sobre assinatura: se o workflow gerar uma keystore nova a cada build, isso chega para testar/instalar, mas para publicar atualizações da mesma app sem forçar desinstalação, precisas de uma keystore fixa como secret do repositório.
